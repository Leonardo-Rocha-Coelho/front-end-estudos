# 💻 Estudos de Front-End

Repositório destinado ao armazenamento e à documentação das atividades práticas desenvolvidas durante as aulas de **Desenvolvimento Front-End**, na graduação em Análise e Desenvolvimento de Sistemas.

O objetivo deste repositório é registrar minha evolução no desenvolvimento web, reunir exercícios realizados em aula e aplicar, na prática, os conceitos estudados.

## 📚 Conteúdos estudados

Durante as aulas, foram desenvolvidas atividades envolvendo os seguintes fundamentos:

### 🌐 HTML5
- Estrutura básica de documentos HTML.
- Utilização de tags e elementos semânticos.
- Organização de conteúdos em páginas web.
- Criação de títulos, parágrafos, listas e links.
- Inserção de imagens e outros elementos.
- Estruturação de formulários.

### 🎨 CSS3
- Integração do CSS com documentos HTML.
- Seletores, propriedades e valores.
- Cores, fontes, margens e espaçamentos.
- Organização e estilização de elementos.
- Construção de layouts.
- Personalização da apresentação das páginas.

### ⚙️ JavaScript
- Introdução à lógica de programação aplicada ao Front-End.
- Fundamentos da linguagem JavaScript.
- Manipulação de elementos HTML.
- Interatividade em páginas web.
- Integração entre HTML, CSS e JavaScript.

## 🎯 Objetivos de aprendizagem

- Desenvolver conhecimentos em desenvolvimento web.
- Compreender a integração entre HTML, CSS e JavaScript.
- Aprimorar a capacidade de resolução de problemas.
- Desenvolver páginas web organizadas e funcionais.
- Praticar a organização e o versionamento de projetos utilizando GitHub.
- Construir uma base sólida para projetos futuros na área de tecnologia.

## 🚀 Evolução contínua

Este repositório será atualizado conforme o avanço das aulas e a realização de novas atividades práticas.

Cada exercício representa uma etapa do meu desenvolvimento como profissional de tecnologia.
