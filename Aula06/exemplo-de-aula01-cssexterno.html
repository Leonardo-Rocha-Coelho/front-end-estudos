O que é o CSS?

Aprendendo CSS externo

O CSS é a camada de apresentação da Web. Ele permite que você estilize o HTML para alcançar as metas de design que você tem em mente para o site. Aqui, você pode encontrar uma variedade de coleções de conteúdo, cursos, padrões e links para outros artigos úteis para guiar você em sua jornada para aprender e usar CSS para deixar suas páginas da Web do jeito que você imaginava!.

O HTML é a estrutura, enquanto CSS é o estilo.
